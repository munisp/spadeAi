# 00 — Evidence Ledger (Elestio reverse-engineering, clean-room)

**Scope:** what Elestio (elest.io) visibly does, recovered only from its **public** surface. No authenticated session, no private API calls, no exploitation, no copied code or brand assets. Each finding has an ID (E-n) that the business, technical and architecture specs cite.

**Method / tooling**
- **REA 6.5.0** (`npm i -g rea-agents`, github.com/morluto/rea), driving a local Chrome over CDP (`127.0.0.1:29229`):
  - `rea inspect-web-page` (DOM, scripts, storage keys, JSON shapes): elest.io, /pricing, dash.elest.io/login, /signup
  - `rea analyze-web-bundle --fetch-source-maps`: routes, endpoint candidates, vendor fingerprints
  - `rea export-web-scripts` → `rea analyze-javascript-application`: static graph of the dashboard bundle (403 modules inventoried, 312 examined; no source maps published)
- Public crawl, text only:
  - elest.io sitemap: 2,835 URLs
  - docs.elest.io sitemap: 196 pages (Docusaurus 3.8.1)
  - api-doc.elest.io: Redoc/OpenAPI 3, 57 operations
- Confidence labels: **Observed** (seen in an artefact), **Stated** (Elestio's own documentation/marketing), **Inferred** (our deduction; flagged as such).

## Weaknesses observed (design inputs for our build)
- W1: JWT in localStorage, sent in request bodies (E3). It is XSS-exfiltratable and skips standard auth middleware. Ours: OIDC (Keycloak), HttpOnly session cookie for the PWA, Bearer tokens for the API.
- W2: RPC verbs and inconsistent casing (`DoActionOnServer` vs `getServices`, duplicated `checkAPIToken`/`checkapitoken`) (E5). Ours: resource-oriented, versioned REST plus an idempotency key on every mutation.
- W3: Push-over-SSH with a mandatory inbound port 22 (E10, E11). Ours: an outbound-only mTLS agent, so customers keep zero inbound management ports.
- W4: The two documents contradict each other on post-deletion retention (7 vs 14 days) and on BYOVM disk price (E10, E12). Ours: one pricing/policy catalogue, versioned in Postgres and rendered everywhere.
- W5: USD-only prepaid billing, card-centric (E8). Ours: NGN-first with Paystack/Flutterwave/Remita, plus USD; postpaid for government via PO/escrow.
- W6: The control plane sits in the EU (E29). Ours: an in-country control plane with data residency under NDPA 2023.
